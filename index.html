AnyTone Firmware Flasher

Update AnyTone DMR radio firmware from your browser over USB. No CPS, no Windows.

This browser cannot access serial ports. Use a desktop version of Chrome, Edge or Opera (Web Serial API), served over HTTPS or from localhost.
Flashing erases the radio's codeplug and contacts. Read and save your codeplug with the CPS first. Use firmware made for your exact model and hardware version.

    How it works
    
        
    The flasher talks to the radio's bootloader over the Web Serial API, the same protocol AnyTone's
        Windows update tool uses. Every official firmware release is bundled with the page, so you pick a model and
        a version and do not download anything. Before writing, it checks that the radio's model and hardware version
        match the firmware. On D578UV radios it also picks the GD32 or AT32 build from the radio's USB ID.
    
        
    Questions
    
        
    Which browsers work?
    
        
    Desktop Chrome, Edge or Opera on Windows, macOS, Linux or ChromeOS. Firefox and Safari do not support
        Web Serial.
    
        
    Will I lose my codeplug?
    
        
    Yes. The on-radio installer erases the codeplug and contacts. Tick "Save a codeplug backup" and the flasher
        reads the radio's memory to a file first. Also save the codeplug with the CPS, because the CPS cannot open
        this raw backup.
    
        
    Can I downgrade?
    
        
    Any bundled version can be written. Use the CPS version that matches the firmware afterwards.
    
        
    Is this official?
    
        
    No. This is an independent open-source tool. It sends the unmodified vendor firmware with the protocol
        documented by reald/anytone-flash-tools and
        qdmr. Use it at your own risk.
